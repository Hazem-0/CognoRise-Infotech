# CognoRise-Infotech

A collection of Flutter applications and internship tasks completed during the **CognoRise Infotech Internship**.
This repository contains multiple beginner-to-intermediate mobile development projects built using **Flutter** and **Dart**.

---

## 📱 Projects Included

### 🧮 Calculator App

A simple calculator application that performs basic arithmetic operations with a clean user interface.

#### Features

* Addition
* Subtraction
* Multiplication
* Division
* Responsive UI

---

### ⚖️ BMI App

A Body Mass Index calculator that helps users calculate their BMI based on height and weight inputs.

#### Features

* BMI Calculation
* Health status result
* User-friendly design
* Real-time input handling

---

### ✅ ToDo App

A task management application for organizing daily activities and improving productivity.

#### Features

* Add tasks
* Delete tasks
* Mark tasks as completed
* Simple and clean interface

---

### ☀️ Summer Training

Contains tasks, experiments, and practice projects completed during summer training sessions.

---
